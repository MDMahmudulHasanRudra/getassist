## Findings

- The source files are raster images about 520–890 px wide. **There is no vector or
  high-resolution master.** A 1024 × 1024 Meta app icon made by upscaling would be soft, so
  none was made.
- Colours were sampled from the PNGs (navy ≈ `#031A41`, blue ≈ `#0E6EEA`, violet ≈
  `#8533EA`). Replace with the original design values when the source file is available.
- The logo has an opaque white background and soft glow, so it is only placed on white.
- The marks appear AI-generated. A designer vector redraw and a trademark search are
  recommended before a wider rollout (not legal advice).

1. Icon as SVG, or PNG ≥ 2048 px on a transparent or plain background.
2. Horizontal lockup (icon + "Get Assist") in the same formats.
3. A simplified favicon that reads at 16 px.
4. Original colour values.

Then rerun `python scripts/brand/prepare-assets.py <folder>` (update the file names in the
script if they change) and produce the 1024 × 1024 Meta icon from the master.
